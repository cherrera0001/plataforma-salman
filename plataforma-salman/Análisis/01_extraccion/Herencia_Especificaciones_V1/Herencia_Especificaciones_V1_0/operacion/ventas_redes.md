# Venta completa desde redes

## Venta por enlace
Enlace permitido en perfil/anuncio/historia dirige al motor propio móvil. Origen/campana se conserva sólo con finalidad habilitada. Buscar -> cotizar -> aceptarcondiciones ->holdcuandoaplica ->intento depago ->verificacionservidor ->confirmacion ->recepción ->notificación ->estadía ->salida ->conciliación. Una consulta no bloquea cuartos; un comprobante no confirma transferencia. Flujo puede usar crédito o pagoallegar sólo con política autorizada.

## Venta por mensaje
APIoficial -> verificacion/inbox -> hilo/opportunity -> humano/asistente autorizado -> fechas exactas y ocupación -> motor disponibilidad y precios -> oferta expirable -> enlace a mismareserva/pago. No segundo inventario en chatbot. Cotización enviada no reserva. Hilo vincula IDs y permite continuar turno. Toma humana pausa bot atomica; modelo no puede afirmarpagado ni aprobar descuentos.

## Activación por capacidad
A.Enlacesweb pueden operar antes de APIdechat. B.Mensajes requieren cuenta,permisos,plantillas/ventanas y bajas. C.Publicación requiere permisos/formato/derechos y aprobación. D.Anuncios requieren presupuesto/titularidad. E.Medición requiere definición deconversion y privacidad. No etiquetar toda red integrada por tener boton. Cada capacidad conserva estado/evidencia/costo propio.
